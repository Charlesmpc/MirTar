把 AI Passport 变成电脑上 Codex 的随身控制器：按 OK 说话，再按 OK 发送，在卡片上阅读回复。实体按键可以翻阅内容、切换会话，不用戴耳机或一直靠近电脑麦克风，手机也能继续做别的事。

默认通过蓝牙添加和连接自己的电脑，无需给卡片预填家中网络；也可导入主机配置，使用可信局域网 Wi-Fi。卡片与电脑之间无需公网中转。

配套 Windows 桥接可以登录后自动运行，保存各会话的工作目录。专用 Agent 会话能在后台执行；追问时可在卡片上选择选项或语音答复，继续原任务。该问答功能仍属实验性功能，桌面与桥接不能同时接管同一会话。Codex 自身仍需联网。封面为概念示意图。
