1. On Windows, install Node.js 24.13+ and Edge, sign in to Codex and create a dedicated session. Extract the matching bridge package and run npm.cmd ci --ignore-scripts in its folder. On first use, run .\tools\New-LocalConfig.ps1 -BluetoothOnly and supply the existing session ID and Codex path when prompted.
2. Select Add server on the card and run .\tools\Add-Server.ps1 on the computer. Enter the card's six-digit code in Windows, then press OK on the card to confirm the computer name.
3. Run .\tools\Start-Bridge.ps1 on the computer. On the card, select the computer under Server list and choose Bluetooth to connect to the session. Bluetooth needs no Wi-Fi setup; reuse the saved computer next time.
4. Press OK to record and OK again to send. UP/DOWN scroll replies; hold them to switch sessions. Hold OK to return home.
5. Optional Wi-Fi: prepare a v2 device file from the repository template with that computer's 2.4 GHz network, password, LAN address and matching bridge binding. Choose Add config-file on the card. Connect a phone or computer to the displayed hotspot using its on-screen password, stay connected despite the no-internet warning, and open http://192.168.4.1. Select the file and click Upload and save configuration. After the saved message and return home, restore the computer's normal network, start the bridge and choose that computer's Wi-Fi on the card. Retry failed uploads; edit and reimport the file to change networks.
