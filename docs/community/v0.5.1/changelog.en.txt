- The home screen now offers Server list, Bluetooth Add server and an explicitly opened Add config-file flow. Public firmware includes no creator hosts or credentials.
- Each computer owns its optional Wi-Fi settings. Import a complete configuration file through the card hotspot; connection failures no longer open automatic Wi-Fi setup.
