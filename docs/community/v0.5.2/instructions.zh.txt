1. 从 GitHub 0.5.2 Release 下载桥接包；Windows 安装 Node.js 24.13+、Edge，登录 Codex 并建专用会话。解压后运行 npm.cmd ci --ignore-scripts；首次运行 .\tools\New-LocalConfig.ps1 -BluetoothOnly，按提示配置现有会话。
2. 卡片选 Add server，电脑运行 .\tools\Add-Server.ps1。在 Windows 输入卡片六位码，再在卡片按 OK 确认电脑。
3. 电脑运行 .\tools\Start-Bridge.ps1；卡片从 Server list 选电脑、Bluetooth 和会话，看到“就绪 OK 录音”即可。默认蓝牙无需配网，下次可直接连接。
4. OK 开始录音，在 10 分钟上限前再按 OK 发送；上下翻阅回复，长按上下切会话，长按 OK 回首页。
5. 可选 Wi-Fi：按仓库 v2 模板填写该主机的 2.4 GHz 网络、密码、电脑地址和桥接绑定。卡片选 Add config-file，手机或电脑按屏幕提示连接热点，保持无互联网连接，打开 http://192.168.4.1，选择文件并点“上传并保存配置”。看到已保存并回首页后，电脑恢复正常网络、启动桥接，卡片选该主机的 Wi-Fi。失败重传；换网修改文件后重导。
