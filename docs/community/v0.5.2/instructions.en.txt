1. Download the Windows bridge from the GitHub 0.5.2 Release. Install Node.js 24.13+ and Edge, sign in to Codex and create a dedicated session. In the extracted folder run npm.cmd ci --ignore-scripts. On first use, run .\tools\New-LocalConfig.ps1 -BluetoothOnly and configure the existing session when prompted.
2. Choose Add server on the card and run .\tools\Add-Server.ps1 on the computer. Enter the card's six-digit code in Windows, then press OK on the card to confirm the computer.
3. Run .\tools\Start-Bridge.ps1. On the card, choose the computer under Server list, then Bluetooth and the session. The ready-to-record prompt confirms connection. Bluetooth needs no Wi-Fi setup; reconnect to the saved computer next time.
4. Press OK to record and OK again before the ten-minute limit to send. UP/DOWN scroll replies; hold them to switch sessions. Hold OK to return home.
5. Optional Wi-Fi: fill the repository's v2 template with that computer's 2.4 GHz network, password, LAN address and matching bridge binding. Select Add config-file on the card. Use a phone or computer to join the displayed hotspot with its on-screen password, stay connected despite the no-internet warning, and open http://192.168.4.1. Select the file and click Upload and save configuration. After the saved message and return home, restore the computer's normal network, start the bridge and choose that computer's Wi-Fi. Retry a failed upload; edit and reimport the file to change networks.
