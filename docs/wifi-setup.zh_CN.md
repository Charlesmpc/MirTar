# 卡片热点配网与本地配置

v0.4.0 将配置移到卡片运行时存储。固件不再读取或嵌入电脑的 `.private/device.config.json`，
不需要为了更换网络重新编译。此版本的无线和实体屏幕行为仍需真机验收；编译、主机测试与真机结果分别报告。

## 打开引导

在卡片选择电脑，按 OK 进入连接方式，再选择 **Wi-Fi**：

- 没有已保存网络：立即打开配网热点。
- 有网络但 30 秒内未获得 IP 地址：自动打开配网热点。
- 曾经连接成功但随后断网：从断网起重新计时 30 秒，仍未恢复则打开配网。
- 在 Wi-Fi 连接方式页或连接等待页，长按上键可立即重新配网。

计时判断的是 Wi-Fi 联网，不是电脑桥接或 Codex 是否在线。Wi-Fi 已连接而桥接未启动时，不会因此触发热点。
已配置电脑后，默认连接方式仍是 Bluetooth。第一次没有电脑配置时，先选择 Wi-Fi 进入设置。

## 手机配置 Wi-Fi

1. 扫描卡片上的 Wi-Fi 二维码连接热点，或在手机 Wi-Fi 列表手动连接屏幕所示的 `MirTar-Setup-XXXXXX`，
   输入屏幕显示的随机密码。提示热点没有互联网时，选择保持连接。
2. 手机浏览器打开 **http://192.168.4.1**。这是固定的本地配网页地址，不保证手机系统自动弹出页面。
3. 填写家庭或办公室的 **2.4 GHz** Wi-Fi 名称与密码，点击“保存并连接 Wi-Fi”。开放网络可留空密码。
4. 网页和卡片显示连接结果；失败或超过 30 秒时，热点保持开启，检查输入后重新提交。
5. 成功且电脑已经配置后，热点关闭，手机切回原网络，卡片继续连接电脑桥接。

新网络优先尝试，其余已保存网络保留，最多八组。同名网络更新密码。
换网时按上述入口重新打开引导；需要清理旧网络时，勾选“仅保留本次 Wi-Fi”。
手机和电脑中均无需访问厂商云端，也没有小程序配网步骤。

## 首次配置电脑与绑定信息

Wi-Fi 连接和 Agent 电脑绑定是两个步骤。首次使用时，在 Windows 登录 Codex、准备专用会话，
在仓库运行以下命令，生成只属于自己的本地配置：

```powershell
.\tools\New-LocalConfig.ps1 -BluetoothOnly
# 或：需要局域网连接时，只询问电脑地址，Wi-Fi 留到网页填写：
.\tools\New-LocalConfig.ps1 -NoWiFiPrompt
```

然后用**这台电脑连接卡片热点**，打开 `http://192.168.4.1`，展开“首次使用：导入电脑配置”，
选择刚生成的 `.private/device.config.json`。

- 只用蓝牙：点击“只导入电脑配置，使用蓝牙”，不必填写家庭 Wi-Fi。卡片回到电脑选择页。
- 使用局域网：生成配置时填写这台电脑的正常局域网 IPv4 地址，导入后填写 Wi-Fi，点击“保存并连接 Wi-Fi”。
  以上两个命令选择其一；不能把蓝牙专用配置中的 `127.0.0.1` 当作卡片要连接的电脑地址。

完成后电脑切回原网络，运行 `tools/Start-Bridge.ps1`。蓝牙首次连接时在 Windows 输入卡片的六位码。
桥接和卡片使用相同的本机随机绑定密钥；没有通用固定密钥。导入的是 `device.config.json`，
不是 `bridge.config.json`，也不是公开的 `device.example.json`。
导入时电脑列表以文件中的 `targets` 为准，多台电脑需放在同一个文件；已有网络会保留并合并。

如果先用手机配好 Wi-Fi、尚未导入电脑配置，热点会继续开放，网页会提示导入电脑配置。
因此可以稍后换电脑连接热点继续完成，无需重新刷机。

## 保存、退出与升级

配置写入卡片 NVS，重启后读取。电脑 JSON 作为编辑和备份入口，不会被卡片自动改写。
保存失败不会报告成功；长按 OK 退出配网并关闭热点。首次配置尚未完成时，下次选 Wi-Fi 会再次引导。
普通固件升级应使用兼容布局并保留 NVS；完整擦除会清掉网络、电脑配置和蓝牙配对记录。

从 v0.3.x 升级时，旧固件里编译进去的配置不会自动迁移，请通过引导导入本机保留的配置文件。
固件升级后无需继续把密码传给编译工具。旧版已验证镜像保留作回退。

热点使用每次进入引导随机生成的 WPA2 密码，网页只接受来自卡片热点的配置请求。
密码与绑定密钥不回传到网页状态接口，也不打印到日志。NVS 当前未启用存储加密，不能声称防物理提取。
若目标 Wi-Fi 也使用 `192.168.4.x` 网段，热点与目标网络可能冲突，这一情况仍需专门验收。
