# v0.5.1

Bluetooth connections that cannot complete binding for one minute now offer **Reset Bluetooth pairing** on the badge.
The owner must confirm with the buttons. Reset clears the badge's Bluetooth bonds while keeping saved hosts, application
binding and Wi-Fi settings. Windows can remove its matching old pairing with
`tools/Start-Bridge.ps1 -ResetBluetoothPairing`, then pair using a new badge PIN.

The bridge also delays application authentication until notification subscription succeeds, buffers the first handshake,
isolates obsolete connection callbacks, and retries/refetches GATT data after subscription failures. Diagnostic logs now
include subscribe timing and card encryption/disconnect status.

All card bonds are cleared because older versions did not record a reliable host-to-Bluetooth-identity mapping.
Other computers must pair again. Old Windows enrollment names may require manual removal. Physical-device acceptance
of the recovery flow is still pending; host/build checks are not proof of a working radio connection.

Public firmware has no preloaded hosts or private credentials. Personal preset images remain local and must not be uploaded.
