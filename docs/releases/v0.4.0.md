# MirTar v0.4.0 — runtime Wi-Fi setup preview

[简体中文](v0.4.0.zh_CN.md)

Configure the badge after flashing one generic image. Selecting Wi-Fi opens a setup hotspot immediately when no network is saved,
or after 30 seconds without a Wi-Fi connection. Scan the badge QR, then open `http://192.168.4.1` to save your network.
Failed attempts keep the page available for correction. Computer settings are imported from your own local device JSON;
Bluetooth-only import does not require home Wi-Fi. Settings persist on the badge instead of being compiled into firmware.

The Windows bridge and same-session Codex voice/reply path are retained. Other OS adapters and Agents remain future work.

## Upgrade

Keep your existing private JSON and verified older image. Flash the generic v0.4.0 image and import your device JSON through setup;
compiled-in v0.3.x settings do not migrate automatically. The partition layout is unchanged; compatible segmented flashing preserves NVS.
Build and flash helpers now default to `.private/build-v0.4.0`. The obsolete build `-Config` argument is rejected.
Use `New-LocalConfig.ps1 -NoWiFiPrompt` to configure a reachable LAN computer while entering home Wi-Fi on the badge page.

## Validation

Configuration/parser/deadline C tests, eight setup-page tests, eight bridge integration/protocol tests and TypeScript checks pass.
Firmware builds are verified against actual flash segments and known private values. See the build manifest for hashes.
**This is a preview: no v0.4.0 physical-device acceptance has been performed.** Wireless, QR, display and persistence behavior
must be verified on hardware. See [validation](../validation/wifi-setup-0.4.0.md) and [setup](../wifi-setup.md).

The hotspot has a random WPA2 password and local-request/CSRF checks. Credentials are not returned by its status endpoint.
NVS is not encrypted; Wi-Fi business traffic remains trusted-LAN plaintext. Keep private configurations, old personalized images,
ELF files and device logs private. The public image has no personal Wi-Fi or binding credentials.
