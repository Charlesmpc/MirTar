# MirTar v0.3.1

[English](https://github.com/Charlesmpc/MirTar/blob/v0.3.1/docs/releases/v0.3.1.md)

AI Passport 卡片作为 Windows Codex 的语音和显示终端。默认 Bluetooth，保留可信局域网 Wi-Fi。
蓝牙修复后，用户已报告真机语音测试通过。

## 更新

- 修复 Windows 配对后 GATT 服务发现失败，改为枚举后按 MirTar UUID 选择。
- 在维持连接前注册通知接收器，避免已配对重连漏收首条 hello。
- 同步协商 MTU，日志提供有界阶段/HRESULT，不输出配对码、语音或正文。
- BLE / Wi-Fi 复用同一套绑定、会话、语音、回复和防重放逻辑。
- Windows PowerShell 刷机预览也校验镜像和分段哈希。
- 更新中英文 README/指南，清理当前文档的本机路径和电脑名；统一版本号，增加隐私审计与发布打包工具。

## 升级与下载

更新源码或桥接包后重启桥接即可。正常工作的 v0.3.0 卡片不必为了本次 Windows 修复重刷；
新编译的固件标识为 v0.3.1。

- `MirTar-v0.3.1-source.zip`：完整源码、占位模板。
- `MirTar-v0.3.1-windows-bridge.zip`：桥接及原生助手源码、启动/配置助手、测试、文档。
- `release-manifest.json` / `SHA256SUMS`：源码提交和文件校验信息。

不上传含真实配置的固件、辅助 EXE、真实配置、录音或设备日志。
参考 [Windows 桥接说明](https://github.com/Charlesmpc/MirTar/blob/v0.3.1/docs/windows-bridge-package.zh_CN.md)和[卡片使用说明](https://github.com/Charlesmpc/MirTar/blob/v0.3.1/docs/device-quickstart.zh_CN.md)。

## 验证边界

原生助手编译、TypeScript、协议和凭据保护测试通过；真卡两轮蓝牙重连、HMAC 绑定、原生会话选择
和已有回复写入通过。随后用户报告语音测试通过。持续吞吐、续航、板卡重启恢复、其他电脑和
连接方式切换仍需更广泛验收。详细记录见[验证文档](https://github.com/Charlesmpc/MirTar/blob/v0.3.1/docs/validation/bluetooth-0.3.0.md)。

本版没有 TTS/朗读、实时工具进度/审批界面、Cursor 或其他主机 OS。
Codex 原生权限、额度和实验接口版本限制仍适用。Wi-Fi 为可信局域网明文，BLE 为认证加密加应用绑定。

## 公开源码与隐私

公开仓库从已审计的 v0.3.1 源码快照开始，不包含此前的私有开发历史。
当前源码、公开 Git 历史和发布资产检查已知本机凭据、常见 token/私钥、生成产物及本机标识。
自动扫描不能保证绝对无敏感信息。

本机隔离模板固件重编译在 bootloader 配置阶段遇到 GCC `-dumpmachine` 空输出，未完成验证。
不发布 v0.3.1 固件，也不声称新版镜像已经真机测试；已验证的 v0.3.0 卡片可以继续使用新版 Windows 桥接。
