# MirTar 0.2.0

Known working Wi-Fi / Windows / Codex baseline before Bluetooth development.

The owner verified the personalized badge firmware on the physical AI Passport:
power-on and Wi-Fi connection, two-press voice capture, delivery to the configured
Codex desktop session, and reply display. The October 25 demo documents this path.
The firmware includes the display-backlight correction from 0.1.0-alpha.1.

This version records that baseline; it does not add Bluetooth or claim sustained
stability, battery-life, multiple-computer or approval coverage. Existing M1 test
and build evidence remains in docs/validation. No configured firmware or private
configuration is included. Build personalized firmware locally.
