# MirTar v0.1.0-alpha.1

[English](v0.1.0-alpha.1.md)

首个 M1 预览版，范围为 FoloToy AI Passport、Windows、可信局域网和已有 Codex 桌面会话。这是尚未完成完整真机验收的预发布版本。

## 变更

- 创建开机界面后将 badge 背光开启到 80%。之前主程序运行时 PWM 占空比保持为零，表现为黑屏。
- 默认桥接端口改为 **TCP 28743**，本机配置助手新增 `-Port` 参数。修改目标端口后，需要重启桥接并重新编译、刷入个人固件。
- 提供卡片 Wi-Fi／绑定／录音／显示实现、Windows 桥接、Codex 原生语音输入、Agent／平台抽象及占位配置模板。
- 真实配置与固件不进入 Git，通过私有路径忽略规则和提交前凭据检查保护。

## 下载内容

- `MirTar-v0.1.0-alpha.1-source.zip`：完整源码快照，包括固件源码和配置模板。
- `MirTar-v0.1.0-alpha.1-windows-bridge.zip`：桥接运行源码、测试、助手和模板，需要 Node.js 并在本机安装依赖。使用步骤见[Windows 桥接包说明](../windows-bridge-package.zh_CN.md)。
- `release-manifest.json`、`SHA256SUMS`：源码提交标识与下载包校验值。

实际卡片固件嵌入 Wi-Fi 密码和绑定密钥。**Release 不上传实际配置的固件、ELF、私有配置或设备日志**，即使仓库是私有的也遵守此要求。个人固件按照[卡片使用说明](../device-quickstart.zh_CN.md)在本机编译。也不提供供刷机的占位固件二进制。

## 验证

- Build：背光修正版个人固件已使用 ESP-IDF 5.5.6／LVGL 9.5.0 构建，并通过镜像分段核对；TypeScript 检查通过。
- Host tests：发布前五项桥接测试、六项凭据保护测试通过。
- Device tests：USB 日志确认原实际配置固件已启动并进入 Wi-Fi 初始化，设备与桥接建立了局域网 TCP 连接。用户反馈在黑屏状态下，真实 badge 语音已进入指定 Codex 桌面会话。
- Unverified：修正版真机背光／显示、回复渲染、持续录音、长时间稳定性、多个真实会话和功耗。用户报告的输入测试对应原实际配置镜像，不代表修正版已通过真机测试。

当前只显示已完成的正式回复。TTS、可靠工具实时进度／审批、Cursor 和其他操作系统不在本次范围内，Codex 原生语音的可用性与额度仍适用。传输明确为可信局域网内的未加密连接，设备通过 HMAC 绑定。
