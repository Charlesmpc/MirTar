# MirTar v0.4.0：运行时配网测试版

[English](v0.4.0.md)

同一份通用固件，刷入后配置。选择 Wi-Fi 时，无已保存网络立即打开热点，有配置但 30 秒未联网也会自动进入。
扫描卡片二维码连接热点，浏览器打开 `http://192.168.4.1` 填写网络；失败后在同一网页修改重试。
电脑信息从自己的本地设备 JSON 导入，只用蓝牙时无需家庭 Wi-Fi。配置保存到卡片，不再编进固件。
保留 Windows 桥接、同一个 Codex 桌面会话的语音和回复；其他 OS 与 Agent 尚未实现。

## 升级

保留原有私有 JSON 和已验证旧镜像。刷入后从引导导入设备配置，旧版编译配置不会自动迁移。
分区布局未改，确认兼容后可分段刷入并保留 NVS。构建和刷机脚本默认目录为 `.private/build-v0.4.0`，
不再接受编译时 `-Config`；`New-LocalConfig.ps1 -NoWiFiPrompt` 可只配置电脑局域网地址，将 Wi-Fi 留到网页填写。

## 验证

配置／解析／超时 C 测试、8 项网页测试、8 项桥接协议／集成测试与 TypeScript 检查通过。
固件按实际分段核对，并扫描已知私人数据；哈希以构建清单为准。
**此版本尚未进行真机验收。** 热点、扫码、屏幕与重启持久化等仍需硬件验证。
见[验证记录](../validation/wifi-setup-0.4.0.md)及[配网说明](../wifi-setup.zh_CN.md)。

热点密码每次随机生成，配置接口有本地请求和 CSRF 校验，状态接口不返回凭据。
NVS 未加密，Wi-Fi 业务链路仍为可信局域网明文。真实配置、旧版个性化镜像、ELF 和日志不能公开。
通用镜像不包含作者的 Wi-Fi 或绑定凭据。
