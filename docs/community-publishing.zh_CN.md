# 发布到 AI Passport 社区

MirTar 当前公开源码和 Windows 桥接包；尚未发布社区通用固件。

## 官方入口与材料

从[玩法社区](https://ai-passport.folotoy.cn/plays/)选择“＋发布玩法”，进入创作者中心。
官方另有发布助手，可协助检查固件、整理双语标题和简介、准备封面与源码链接；
由创作者在官网登录授权，预览内容后再确认上传。

依据[官方发布说明](https://github.com/FoloToy/ai-passport/blob/main/docs/development/release/publish-to-community.zh_CN.md)，需要：

- 完整合并镜像，从 `0x0` 刷入；不能使用单独的应用镜像。
- JPEG / PNG / WebP 封面，最多 10 MiB。
- 公开 HTTPS Git 仓库地址，以及中英文标题、简介。

MirTar 的合并镜像名为 `MirTar-full.bin`；上传前需按发布助手要求验证布局和打包格式，不能只改文件名。
正式表单与最终校验以官网当时显示为准。

## v0.4.0 的配置方式与发布校验

v0.4.0 已实现热点配网与 NVS 运行时配置，构建不再读取私人 JSON。
选择 Wi-Fi 时，无配置立即引导；有配置但 30 秒未连接时自动引导。
手机连接卡片屏幕上的随机密码热点后访问 `http://192.168.4.1`。
电脑绑定信息通过网页导入本机生成的设备配置；只用蓝牙也可导入，无需家庭 Wi-Fi。
详见[完整步骤](wifi-setup.zh_CN.md)。

只允许发布本次成功构建并校验的通用合并固件。旧版镜像仍包含私人凭据，不能因为源码已公开就上传。
构建验证会核对分段、版本并扫描已知本机凭据与个人标识。扫描不能保证绝对无敏感数据。
编译与主机测试不代表真机验收；投稿必须如实说明本版尚未验证的无线与屏幕行为。

封面和 demo 只使用测试内容，避免出现私人 Wi-Fi、电脑名、会话正文或通知。

## 建议投稿文案

中文标题：MirTar｜把电脑上的编程 Agent 带到手里

英文标题：MirTar | Your coding agent, in your hand

简介：按键说话、屏幕看回复，通过蓝牙或局域网直接连接电脑，继续操作同一个 Codex 会话。
设备传输、Agent 与 OS 分别适配；当前实现 Windows 和 Codex，后续计划支持 macOS、Linux。
无需给卡片控制链路开放公网入口。需配套电脑桥接和已登录的 Codex；Agent 本身仍需正常联网。
